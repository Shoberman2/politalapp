# Code of Conduct

BallotWatch is a civic data project. People should be able to contribute,
question, correct, and learn without being harassed or drowned out.

## Expected Behavior

- Be respectful and specific.
- Assume good faith until there is clear evidence otherwise.
- Critique claims, code, data, and methodology, not people.
- Back factual corrections with public sources.
- Help newcomers find the right file, issue, or command.
- Keep political disagreement from becoming personal hostility.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without consent.
- Coordinated spam, brigading, or bad-faith correction floods.
- Misrepresenting BallotWatch data as an official government statement.
- Using issues or pull requests for campaign messaging instead of project work.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues; block users; or
pause a discussion when behavior harms the project. Serious security issues and
private conduct reports should use the private reporting path in `SECURITY.md`.

## Scope

This code applies in repository discussions, issues, pull requests, project
documentation, and official community spaces connected to BallotWatch.
