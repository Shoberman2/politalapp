# Corrections

BallotWatch should make factual correction easy, careful, and source-backed.

## What Counts As A Correction

- A wrong vote position.
- A wrong bill title, sponsor, action, or committee.
- A stale member party, district, or term.
- A broken source URL.
- A methodology page that no longer matches the code.

## What Does Not Count

- Disagreement with a member's vote.
- Campaign messaging.
- Claims without a public source.
- Requests to change neutral language into partisan framing.

## Required Evidence

Correction reports should include:

- BallotWatch URL or record ID.
- Field that appears wrong.
- Expected value.
- Public source URL.
- Short explanation.

## Review

Maintainers review corrections, update code or data where appropriate, and note
accepted material corrections in a public changelog or correction log.
