# BallotWatch Data

## The full record (bulk download)

Every member, member term, bill, cosponsorship, roll call, and member vote
BallotWatch has, rebuilt daily (about 07:30 UTC) as gzip CSV and gzip NDJSON:

- Files: `https://www.ballotwatch.io/data/full/` (for example `votes.csv.gz`
  for the full archive, `votes-119.csv.gz` for the current Congress)
- Manifest (file list, row counts, sizes, SHA-256):
  `https://www.ballotwatch.io/data/full/manifest.json`, also at
  `GET /api/v1/datasets`
- Schemas (Frictionless Data Package):
  `https://www.ballotwatch.io/data/full/datapackage.json`
- Past snapshots: `https://www.ballotwatch.io/data/archive/YYYY-MM-DD/` (14 days)
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), public
  domain dedication. See `DATA_LICENSE.md` in the repository. The federal
  source records are public domain.

The files are generated by `etl/exportOpenData.ts` and served from public
Supabase Storage through a rewrite in `vercel.json`. Gzip files download as
`application/gzip`; decompress them yourself (`gunzip votes.csv.gz`).

## Samples in this folder

The files here are small schema samples for a first look, classrooms, and
prototypes. They are not complete. Use them to understand field names, stable
ids, source URLs, and how members, bills, and votes connect. See
`datapackage.json` here for their schema, and the full package above for
everything.
