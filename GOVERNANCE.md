# Governance

BallotWatch is maintainer-led. The project accepts community contributions, but
maintainers are responsible for final decisions on product scope, data
methodology, moderation, releases, and security.

## Decision Principles

1. Source-backed facts beat interpretation.
2. Editorial trust beats visual novelty.
3. Public methods beat hidden heuristics.
4. Small, reviewable changes beat broad rewrites.
5. Civic usefulness beats partisan positioning.

## Maintainer Responsibilities

- Review pull requests and correction reports.
- Keep data methodology visible.
- Protect secrets and user data.
- Enforce the code of conduct.
- Explain why substantial contributions are accepted, deferred, or declined.

## Contributor Path

Regular contributors can earn broader review trust by making source-backed,
well-tested, scoped contributions over time. Commit access is not automatic and
may be granted or removed by maintainers.

## Data and Methodology Changes

Methodology changes must include:

- What changed.
- Why it changed.
- Which records are affected.
- Source references.
- Version or migration notes when public outputs change.
